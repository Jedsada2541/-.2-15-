ระบบสอบออนไลน์ ม.2 การออกแบบและเทคโนโลยี

คุณสมบัติ
- Static Website ใช้ HTML, CSS, JavaScript เท่านั้น
- ไม่ต้อง Login
- ไม่ต้องมีฐานข้อมูล
- ไม่ใช้ localStorage หรือ sessionStorage
- ก่อนสอบให้นักเรียนกรอกชื่อและเลขประจำตัว
- มีระบบจับเวลา 1 ชั่วโมง
- ถ้าหมดเวลา ระบบจะส่งข้อสอบอัตโนมัติทันที
- ถ้านักเรียนทำเสร็จก่อนเวลา สามารถกดส่งคำตอบก่อนได้
- เมื่อส่งคำตอบ จะแสดงคะแนนพร้อมชื่อผู้สอบทันที
- ถ้านักเรียนไม่ผ่าน ระบบจะล็อกการสอบซ้ำในหน้าเว็บนั้น
- ครูปลดล็อกด้วยรหัสผ่าน 1234
- พิมพ์ผลคะแนนได้
- Deploy ได้ทันทีบน Netlify หรือ Vercel

วิธีใช้งาน
1. แตกไฟล์ zip
2. เปิดไฟล์ index.html เพื่อทดสอบ
3. ถ้าต้องการ Deploy ให้ลากโฟลเดอร์ m2-tech-exam ไปวางใน Netlify Drop หรืออัปโหลดขึ้น GitHub แล้ว Import เข้า Vercel

การแก้รหัสผ่านครู
เปิดไฟล์ script.js แล้วแก้บรรทัด:
const TEACHER_PASSWORD = '1234';

การแก้เกณฑ์ผ่าน
เปิดไฟล์ script.js แล้วแก้บรรทัด:
const PASS_SCORE = 15;

การแก้เวลาสอบ
เปิดไฟล์ script.js แล้วแก้บรรทัด:
const EXAM_DURATION_MINUTES = 60;

หมายเหตุสำคัญ
ระบบนี้ไม่บันทึกข้อมูลใด ๆ ตามเงื่อนไขที่กำหนด ดังนั้นสถานะล็อกการสอบซ้ำจะอยู่เฉพาะขณะเปิดหน้าเว็บนั้นเท่านั้น หากปิดหน้า/รีเฟรชหน้า ระบบจะเริ่มใหม่ เพราะไม่มีฐานข้อมูลและไม่มีการเก็บข้อมูลในเครื่อง
